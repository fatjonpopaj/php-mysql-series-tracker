\# PHP MySQL Series Tracker



University web application for managing and filtering personal TV series.



\## Technologies



\- PHP

\- MySQL

\- SQL

\- HTML

\- CSS

\- MySQLi



\## Features



\- User login

\- Display personal series

\- Filter series by title, genre and platform

\- Create new series entries

\- Relational MySQL database

\- User-to-series relationships



\## Database



The application uses a MySQL database with the following main tables:



\- `user`

\- `series`

\- `userSeries`



The database schema is located in:



`db/db.sql`
